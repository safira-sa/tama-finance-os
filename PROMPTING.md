# Codex Development Rules

You are working on Tama OS.

Before making any change:

- Understand existing code first.
- Preserve existing functionality.
- Do not rewrite working components.
- Keep commits small.
- Explain architectural decisions.
- Avoid introducing frameworks unless requested.
- Prefer vanilla JavaScript.
- Prioritize maintainability.
- Stop after completing the requested milestone.

Never:

- Rewrite the entire project.
- Change UI without request.
- Remove existing features.
- Add unnecessary dependencies.
- Create placeholder code unless requested.

The goal is to evolve the existing system, not replace it.
