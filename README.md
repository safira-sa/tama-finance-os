# tama-finance-os

> A personal operating system for finance, investing, and research.

Tama OS consists of two standalone HTML applications:

- 📈 **Finance OS** → personal finance, investment management, portfolio tracking, and financial planning.
- 🔬 **Research Desk** → equity research, watchlists, investment scoring, and thesis management.

Both applications are fully client-side, require no installation, and store data locally.

---

# Philosophy

These tools were built around one idea:

> **Information should lead to decisions.**

Instead of collecting spreadsheets, notes, screenshots, and watchlists across multiple apps, Tama OS centralizes everything into a single workflow.

The goal isn't replacing professional software.

The goal is reducing friction.

# Why HTML?

The entire project runs inside your browser.

Advantages:

- No installation
- No backend
- No database server
- No subscription
- No cloud dependency
- Works offline
- Portable

Just open the HTML file.

---

# Data Storage

The applications store information locally inside the browser.

For backups:

- Export JSON
- Save the file
- Import whenever needed

Regular backups are highly recommended.
